# Zadání pro praktické zkoušení: Unit testy

Každý student pracuje samostatně na zadané třídě podle své skupiny.

## Pravidla a pokyny
* **Samostatná práce:** Každý si stáhne pouze třídu pro svou skupinu a vypracuje k ní unit testy.
* **Zákaz AI a našeptávačů:** Vypněte si AI našeptávače i automatické dokončování kódu (Copilot apod.). Je přísně zakázáno využívat AI chatboty.
* **Povoleno:** Můžete používat pouze své vlastní poznámky a oficiální dokumentaci.
